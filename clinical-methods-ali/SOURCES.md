# Reference sources used for the scientific review (checked September 2026)

Every value changed in the book is logged in `CHANGELOG-editorial.md`, together with the original wording.

| Topic | Source |
|---|---|
| Adult lab reference ranges (electrolytes, creatinine, glucose, enzymes, Hb, platelets, RBC indices, ESR, lipids, ABG, B12) | Medscape, *Lab Values, Normal Adult* (updated Jul 2025): https://emedicine.medscape.com/article/2172316-overview |
| Anaemia thresholds (Hb < 13 men, < 12 women) | WHO haemoglobin thresholds (via PubMed 26404438) |
| CSF glucose 45–80 mg/dL (≈ 60% of plasma), protein 15–45 mg/dL | Medscape, *CSF Analysis*: https://emedicine.medscape.com/article/2093316-overview |
| Semen reference limits | WHO Laboratory Manual, 6th ed. (2021) |
| Normal QRS axis −30° to +90° | ECGpedia (https://en.ecgpedia.org/wiki/QRS_axis); Geeky Medics |
| T-wave amplitude < 5 mm limb leads / < 10 mm chest leads | Standard ECG texts (e.g. Hampton, *The ECG Made Easy*); cardiolatina review |
| PR 0.12–0.20 s; QRS < 0.12 s; QTc < 0.44 s (men) / < 0.46 s (women) | Standard ECG references |
| Bradycardia < 50/min; normal heart rate 50–100/min | 2018 ACC/AHA/HRS Bradycardia Guideline (Kusumoto et al.) |
| Adult respiratory rate 12–20/min | Standard clinical-methods texts (Macleod's, Talley & O'Connor) |
| Blood-pressure categories | WHO / ESC 2023–2024 (≥ 140/90 hypertension); ACC/AHA 2017 (≥ 130/80) |
| Severe mitral stenosis ≤ 1.5 cm²; severe aortic stenosis ≤ 1.0 cm² or mean gradient ≥ 40 mmHg | 2020 ACC/AHA Valvular Heart Disease Guideline |
| Exercise ECG positive: ≥ 1 mm horizontal/down-sloping ST depression | ACC/AHA exercise-testing guideline |
| Brain death: core temperature ≥ 36 °C; apnoea test PaCO₂ ≥ 60 mmHg | AAN/AAP/CNS/SCCM 2023 consensus (Greer et al.) |
| Pleural aspiration ≤ 1.5 L at one sitting | British Thoracic Society pleural guideline (2023) |
| Liver span 6–12 cm (MCL) | Macleod's Clinical Examination |
| Fetal heart rate 110–160/min | FIGO intrapartum fetal monitoring consensus |
| LVH voltage (Sokolow-Lyon): S V1 + R V5/6 > 35 mm; R aVL ≥ 11 mm | Sokolow & Lyon 1949; standard ECG texts |

## Figures
All 57 figures in this edition are **schematic teaching diagrams drawn for this book**
(source code in `tools/figures/`). ECG traces are synthetic, drawn to the standard
calibration of 25 mm/s and 10 mm/mV. They are not copied from any other book, so there are no copyright issues.
Real chest X-ray images for chapter 5 have **not** been added, because no licensed images are available.
