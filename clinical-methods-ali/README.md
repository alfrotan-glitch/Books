## Rebuild
```
python3 tools/edit_master.py   # original -> master (logged)
./build.sh                     # master -> build/ (DOCX, PDF, EPUB + epubcheck)
cp build/*.{pdf,epub,docx} release/
```
Toolchain: `pip install --break-system-packages --user pypandoc_binary typst jdk4py epubcheck pymupdf`
