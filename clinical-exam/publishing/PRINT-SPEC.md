# مشخصات چاپ

| مورد | مقدار |
|---|---|
| قطع | A5 (۱۴۸ × ۲۱۰ ملی‌متر) |
| صحافی | جلد نرم، چسبی گرم (perfect bound)؛ **شیرازه در طرف راست** (کتاب راست‌به‌چپ) |
| فایل داخل | `build/moayena-clinical-print-interior.pdf` (تعداد صفحات زوج؛ هر بار ساختن، تعداد را دوباره ببینید) |
| کاغذ داخل (پیشنهاد) | افست بی‌پوشش ۷۰ یا ۸۰ گرام؛ سفید یا کریمی |
| چاپ داخل | رنگی (شکل‌ها و جعبه‌ها رنگی اند). برای نسخه ارزان سیاه‌وسفید، فایل خاکستری جداگانه با مطبعه هماهنگ شود |
| جلد | کارت ۲۵۰–۳۰۰ گرام، لمینیت مات یا براق |
| فایل جلد | `python3 tools/cover/make_cover.py --caliper <ضخامت هر صفحه>`؛ خونریزی ۳ ملی‌متر در هر طرف |
| ضخامت شیرازه | تعداد صفحات × ضخامت هر صفحه. مثال: ۴۸۶ × ۰٫۰۵۵ ≈ ۲۶٫۷ ملی‌متر |
| وضاحت تصاویر | شکل‌های داخل برداری (SVG) اند؛ جلد در ۳۰۰ dpi ساخته می‌شود |
| رنگ | فایل‌ها RGB اند؛ تبدیل به CMYK را مطبعه با پروفایل خود انجام دهد و یک نمونه رنگی (proof) بدهد |

## پیش از چاپ از مطبعه بپرسید
1. ضخامت دقیق کاغذ انتخاب‌شده (ملی‌متر در هر صفحه).
2. کمترین ضخامت شیرازه برای نوشتن عنوان روی آن.
3. آیا حاشیه داخلی (gutter) ۲۱ ملی‌متر برای صحافی چسبی کافی است؟
4. پروفایل رنگ و نیاز به PDF/X.
5. قیمت نسخه آزمایشی (یک یا دو جلد) پیش از چاپ کامل.
