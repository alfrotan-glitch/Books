# معاینه کلینیکی: از تاریخچه تا تشخیص — new original book

**Author:** داکتر الله یار فروتن · **Language:** Afghan Dari · **Status:** v1.0, first edition (1405), approved by the author on 2026-09-24 — front matter, 27 chapters (4 parts), 135 bedside rules, appendices (rules, OSCE guide, normal values, Dari–English glossary, references, subject index with page numbers). Not yet obtained (not blocking digital publication): specialist medical sign-off, ISBN/publisher.

This book is written from scratch. The old manuscript («میتودهای کلینیکی علی») is **not** used as a text source. Originality is checked with `tools/similarity.py` against both the original and the edited old text; the current result is **0 shared 8-word sequences**.

- Plan and chapter list: `BLUEPRINT.md`
- Voice and box conventions: `STYLE-GUIDE.md`
- Sources: `SOURCES.md`
- Chapters: `chapters/NN-*.md`; appendices `chapters/9N-*.md`. Assembled by `tools/assemble.py`; the bedside-rules and OSCE-guide appendices are generated automatically. The subject index (`chapters/94-index.md`, terms from `tools/index-terms.txt`) gets real page numbers in the PDF only.
- Figures: generated by `tools/figs/*.py` into `assets/`.
- Build: `./build.sh`, then `python3 tools/cover/make_cover.py`. Outputs go to `build/`; the release files are copied to `release/`: `moayena-clinical-v1.0.pdf` (screen), `.epub`, `-print-interior.pdf`, `-print-cover.pdf`.
