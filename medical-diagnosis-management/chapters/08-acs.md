# فصل ۸ — سندروم کرونری حاد: سکته قلبی (Acute Coronary Syndrome / Myocardial Infarction)

> **بخش دوم — سیستم قلب و عروق**

🖼 **تمثیل ذهنی:** عروق قلب مثل لوله‌های آبی هستند که چربی (پلاک) در دیوارهٔ آن‌ها رسوب کرده. یک روز، یک تکه از این رسوب **می‌شکند** و خون روی آن لخته می‌شود (ترومب) — لوله کاملاً بسته می‌شود و عضلهٔ قلب از آن طرف «بی‌آب» می‌ماند و می‌میرد. هر دقیقه تأخیر = بیشتر عضلهٔ مرده. پس این مریض **زمان است** — Time is Muscle.

## 🔹 ۱. Core Concept (مفهوم بنیادی)

سندروم کرونری حاد (ACS) طیفی است که شامل سه شکل می‌شود:
1. **سکته قلبی با بالا رفتن خط ست (STEMI):** انسداد کامل شریان → آسیب ترانس‌مولاری (Transmural) — **عاجل‌ترین**
2. **سکته قلبی بدون بالا رفتن خط ست (NSTEMI):** انسداد ناقص/گذرا → آسیب ساب‌اندوکاردیال (Subendocardial)
3. **آنژین ناپایدار (Unstable Angina):** ایسکمی بدون مرگ سلولی (تروپونین منفی)

⚗️ **فرمول:** `ACS = پلاک شکسته + ترومب = انسداد عروق → ایسکمی/نفارکتوس — تداوی = باز کردن عروق + جلوگیری از ترومب بیشتر`

## 🔹 ۲. Definition & Classification (تعریف و تصنیف)

**تعریف:** سندروم کرونری حاد یک سندروم بالینی است که بر اثر کاهش ناگهانی خون‌رسانی به عضلهٔ قلب ایجاد می‌شود.

| نوع | ST | تروپونین | مکانیزم |
|---|---|---|---|
| **STEMI** | بالا (ST Elevation) | ↑ | انسداد کامل (100٪) شریان |
| **NSTEMI** | بدون (یا ST depression) | ↑ | انسداد ناقص (50–90٪) |
| **Unstable Angina** | بدون | نرمال | انسداد گذرا |

**طبقه‌بندی بر اساس فاصله زمانی (Killip برای سکته):**
- کلاس ۱: بدون علایم عدم کفایه قلب
- کلاس ۲: عدم کفایه خفیف (رال / S3)
- کلاس ۳: عدم کفایه شدید (ادیما ریوی)
- کلاس ۴: شوک

## 🔹 ۳. Pathophysiology — Step-by-step

⚗️ **فرمول:** `پلاک شکننده (Vulnerable Plaque) ← شکستن (Rupture) ← ترومب (Thrombus) ← انسداد ← ایسکمی (Ischemia) ← نفارکتوس (Infarction)`

1. **قدم ۱ — تشکیل پلاک:** اتروسکلروز (Atherosclerosis) — لیپید + کلسترول + ماکروفاژ در دیوارهٔ شریان.
2. **قدم ۲ — پلاک شکننده (Vulnerable Plaque):** پلاک بزرگ با هستهٔ لیپیدی بزرگ و کلاهک نازک → مستعد شکستن.
3. **قدم ۳ — شکستن پلاک:** استرس، فشار خون بالا، سیگار → پلاک می‌شکند → محتویات (تکسیبی‌لین) با خون تماس می‌گیرند.
4. **قدم ۴ — ترومب:** پلاکت‌ها چسبیده و ترومب می‌سازند (ترومب سفید + قرمز) → انسداد کامل یا ناقص.
5. **قدم ۵ — ایسکمی:** عضلهٔ قلب بدون اکسیژن می‌ماند → آسیب سلولی → مرگ (نفارکتوس).
6. **قدم ۶ — نشت آنزیم‌ها:** **تروپونین** (Troponin I/T) به خون نشت می‌کند (معیار تشخیصی).
7. **قدم ۷ — بازسازی/بازتوزیع:** رگ‌های جدید (کالاجن) جایگزین می‌شوند → اسکار (Scar) → تغییر شکل (Remodeling) → عدم کفایه قلب.

🖼 **تصویر:** «پلاک = رسوب لوله آب، شکستن = ترک، ترومب = لخته، انسداد = بسته شدن لوله، نفارکتوس = مرگ بافت پشت لوله.»

## 🔹 ۴. Etiology & Risk Factors (اسباب و فکتورهای مساعد)

| فکتور | خطر |
|---|---|
| **فشار بلند خون (Hypertension)** | شایع‌ترین — آسیب اندوتلیال |
| **دیابت (Diabetes)** | ۲–۴ برابر خطر — اتروسکلروز شتابان |
| **سیگار (Smoking)** | ۲–۴ برابر — ایسکمی + ترومب |
| **هایپرلیپیدمی (Hyperlipidemia)** | LDL بالا — تشکیل پلاک |
| **چاقی / چاقی شکمی** | اتروسکلروز + التهاب |
| **سن / جنس** | مردان >۴۵، زنان >۵۵ |
| **سابقه خاندان (Family History)** | MI در مرد <۵۵ / زن <۶۵ |
| **کم‌تحرکی** | اتروسکلروز |
| **استرس مزمن** | فعالی‌شدن سیمپاتیک |
| **الکلی زیاد** | فشار خون + لیپید |
| **سابقه ACS / CAD** | خطر تکرار |
| **آنمی مزمن** | کم‌رسانی اکسیژن |

## 🔹 ۵. Symptoms & Signs (اعراض و علایم)

**اعراض:**
- **درد قفسه سینه (Chest Pain):** فشار/سنگینی/سوزش، پشت جناغ استرن، انتشار به بازوی چپ / فک / شانه / کمر. **۱۵–۶۰ دقیقه** طولانی (نه چند ثانیه). با فعالیت بدتر، با استراحت/نیتروگلیسیرین بهتر.
- **تنگی نفس (Dyspnea)** — اغلب هم‌زمان با درد
- **تعریق سرد (Cold Sweat)**
- **تهوع / استفراغ (Nausea/Vomiting)**
- **سرگیجه / سنینکوپ (Dizziness/Syncope)**
- **ترس از مرگ (Sense of Doom)**
- **در زنان / مسنان / دیابت:** اعراض «بی‌حرفه‌ای» — تنگی نفس، ضعف، درد شکم، تهوع — **بدون درد سینه** (Silent MI)

**علایم:**
- **تعریق سرد + بی‌قراری + رنگ‌پریدگی** (کلاسیک)
- **تاکیکاردی** (رایج‌ترین) یا برادی‌کاردی (در inferior MI)
- **فشار خون بالا** (درد) یا **پایین** (shock / RV infarction)
- **S3 Gallop** (عدم کفایه حاد)
- **RAL / ادیما ریوی** (Killip III)
- **کاهش پالس / سردی دست‌وپا** (Killip IV)
- **ECG:** ST elevation (STEMI) / ST depression / T inversion / Q waves

## 🔹 ۶. Clinical Examination (معاینه)

📋 **چک‌لیست معاینه ACS:**
- ☐ علایم حیاتی: BP (هر دو بازو)، HR، RR، SpO2، دما
- ☐ **درد سینه:** ویژگی (SOCRATES: Site, Onset, Character, Radiation, Associated, Time)
- ☐ **قلب:** ریتم، S3/S4، وزش نو (MR / VSD)
- ☐ **ریه:** Rales، SpO2
- ☐ **JVP + ادیما پا** (RV infarction در inferior MI)
- ☐ **ECG 12 لید در ۱۰ دقیقه اول** (معیار طلایی)
- ☐ **پالس محیطی** (دیسکسیون؟)
- ☐ **معاینه عصبی** (سکته مغزی هم‌زمان؟)

## 🔹 ۷. Quick Differential Diagnosis (تشخیص تفریقی)

| تشخیص | نکته تمایز |
|---|---|
| **دیسکسیون اورت** | درد «پاره‌شده»، انتشار به کمر، اختلاف فشار بازوها، پالس‌های نامتقارن |
| **امبولی ریوی (PE)** | تنگی نفس حاد، DVT، D-dimer، CTPA |
| **پریکاردیت** | درد با حالت (بهتر در قوس)، فریکشن راب، ST elevation گسترده + PR depression |
| **آپنه معده (GERD/Spasm)** | سوزش، با غذا، نیتروگلیسیرین اثر کم، ECG نرمال |
| **کوستوکندریت** | درد موضعی، با لمس بدتر، بدون ECG تغییر |
| **سینه‌نشی (Pneumothorax)** | تنگی نفس + کاهش صدای زنگ، CXR |
| **آنژیوکینتیک (Takotsubo)** | بعد از استرس، ECG ST elevation، CAG بدون انسداد |
| **سکته مغزی (Stroke)** | ضعف یک‌طرفه، CT مغز |

## 🔹 ۸. Investigations — Basic → Advanced

**بنیادی (همه Mریضان ACS):**
- **ECG 12 لید:** **در ۱۰ دقیقه اول** — ST elevation / depression، T inversion، Q waves
- **Troponin (I یا T):** حساس / سریع (High-sensitivity) — در 0, 1, 3 ساعت
- **CBC:** آنمی / انتان
- **RFT + الکترولیت‌ها:** قبل از دواها
- **LFT:** کبد چپ
- **Coagulation (PT/INR/aPTT):** قبل از آنتی‌کواگولاسیون
- **CXR:** عدم کفایه قلب، دیسکسیون
- **لیپید + قند + HbA1c:** فکتورهای خطر
- **BNP/NT-proBNP:** عدم کفایه قلب هم‌زمان

**پیشرفته / ویژه:**
- **ECG تکرار:** هر ۱۵–۳۰ دقیقه (تغییر ST)
- **Echo (TTE):** دیواره‌های متحرک (Wall Motion Abnormality)، LVEF، RV
- **Cath / CAG (Coronary Angiography):** معیار طلایی — در STEMI (Primary PCI) / NSTEMI (Early Invasive)
- **CT Angiography:** در شبهه دیسکسیون / PE
- **D-dimer:** PE

## 🔹 ۹. Diagnosis & Diagnostic Criteria

**تشخیص STEMI (ESC 2023):**
- **ST elevation در ۲ لید مجاور** (J-point):
  - V2–V3: ≥ ۲ mm در مردان ≥ ۴۰ سال، ≥ ۲.۵ mm در مردان < ۴۰ سال، ≥ ۱.۵ mm در زنان (→ فصل ۲)
  - سایر لیدها: ≥ ۱ mm
- **LBBB جدید** (با اعراض)
- **تروپونین بالا** (اگر ECG مبهم)

**تشخیص NSTEMI:**
- **Troponin بالا** (≥ 99th percentile) + **بدون ST elevation** + اعراض ایسکمیک
- **GRACE Score** برای طبقه‌بندی خطر (Early Invasive vs Conservative)

## 🔹 ۱۰. Management (تداوی)

### الف) Emergency & General Care (اقدامات عاجل)

📋 **الگوریتم STEMI (Time-Critical):**
1. **قدم ۱ — ECG در ۱۰ دقیقه** + تشخیص STEMI
2. **قدم ۲ — Antiplatelet + Anticoagulant فوری** (زیر)
3. **قدم ۳ — Reperfusion:**
   - **Primary PCI:** اگر در **۹۰ دقیقه** (FMC-to-Device) ممکن است → **PCI**
   - **Fibrinolysis:** اگر PCI ممکن نیست → **Fibrinolytic در ۳۰ دقیقه** (Door-to-Needle)
   - اگر هیچ‌کدام ممکن نیست → انتقال به مرکز PCI
4. **قدم ۴ — بعد از Reperfusion:** CAG + PCI
5. **قدم ۵ — Secondary Prevention:** Statin + ACEI + Betablocker + دوا‌های ضد پلاکت

📋 **الگوریتم NSTEMI:**
1. **ECG + Troponin** (در 0 و 1/3 ساعت)
2. **Antiplatelet + Anticoagulant** (Clopidogrel/Ticagrelor + Heparin/Enoxaparin)
3. **GRACE Score:**
   - **High Risk** (GRACE > 140 / ST تغییر / HF / arrhythmia) → **Early Invasive (CAG+PCI در 24 ساعت)**
   - **Low Risk** → تست ورزش / CTA / Medical Management

**کنترااندیکاسیون‌های مطلق Fibrinolysis:**
- خونریزی مغزی سابق (ICHD)
- سکته مغزی ischemic در ۳ ماه اخیر
- شک به دیسکسیون اورت
- خونریزی فعال / اختلال انعقادی
- تروما سر/صورت شدید در ۳ ماه اخیر
- تومور مغزی / آنوریسم / AVM

### ج) Non-pharmacological Management
- **استراحت مطلق** در فاز حاد
- **اکسیژن** فقط اگر SpO2 < ۹۰٪
- **کنترل درد** (Morphine)
- **پایش ECG** (Monitor)
- **رژیم کم‌نمک / کم‌چربی**
- **ترک سیگار** (مهم‌ترین فکتور قابل تغییر)
- **Cardiac Rehabilitation** (بعد از ترخیص)
- **واکسیناسیون آنفلوانزا** (هر سال)

### د) Surgical / Procedural Management
- **Primary PCI (Percutaneous Coronary Intervention):** بیلینگ + استنت (DES) — معیار طلایی STEMI
- **CABG (Coronary Artery Bypass Graft):** سه‌شانه‌ای / Cx چپ / LAD — اگر PCI ممکن نیست
- **IABP / ECMO / Impella:** در shock / مکانیکal complication
- **Joint / Valve Repair:** در VSD / MR حاد

## 🔹 ۱۱. Complications (اختلاطات)

| اختلاط | زمان |
|---|---|
| **NSTEMI / Re-infarction** | هر زمان |
| **Heart Failure (Killip III/IV)** | ۱–۴ روز |
| **Cardiogenic Shock** | ۱–۷ روز |
| **Arrhythmia (VF / VT / SVT / Brady)** | ۱–۷۲ ساعت |
| **Mechanical Complication (VSD / Papillary Muscle Rupture / Free Wall Rupture)** | ۳–۷ روز |
| **DVT / PE** | بعد از استراحت مطلق |
| **Dressler Syndrome (پریکاردیت بعد از MI)** | ۲–۸ هفته |
| **Depression / PTSD** | بعد از ترخیص |
| **Renal Failure (Contrast)** | ۴۸–۷۲ ساعت بعد از CAG |

## 🔹 ۱۲. Prognosis & Follow-up
- **پروگنوز:** با PCI سریع + Secondary Prevention، مرگ‌ومیر ۳۰ روزه < ۵٪. بدون تداوی، مرگ‌ومیر بالا.
- **پیگیری:**
  - **ترخیص:** ۳–۵ روز (STEMI) / ۲–۴ روز (NSTEMI)
  - **ECG + Echo:** قبل از ترخیص + ۶ هفته بعد
  - **Lipid + LFT:** ۴ هفته بعد از Statin
  - **RFT:** ۴۸–۷۲ ساعت بعد از CAG
  - **Stress Test:** ۶–۸ هفته بعد (اگر Conservative)
  - **کنترل فشار / قند / لیپید:** هر ۳ ماه
  - **Secondary Prevention:** Aspirin + P2Y12 (۱۲ ماه) + Statin + ACEI + Betablocker + ترک سیگار + ورزش

## 💡 Memory Joggers (نکات طلایی)
1. **Time is Muscle.** هر ۳۰ دقیقه تأخیر در Reperfusion = بیشتر عضلهٔ مرده.
2. **STEMI = PCI در ۹۰ دقیقه / Fibrinolytic در ۳۰ دقیقه.**
3. **Aspirin ۳۰۰ mg chewed** — اولین دوا که مریض می‌خورد (حتی قبل از ECG).
4. **Ticagrelor ۱۸۰ mg → ۹۰ mg BID** — از Clopidogrel بهتر در ACS.
5. **Nitroglycerin را در RV infarction (inferior MI + JVP بالا) نده** — hypotension.
6. **Betablocker را در HF / shock / bradycardia نده.**
7. **Troponin 0 و 1 ساعت** — اگر بالاتر از 99th percentile = NSTEMI.
8. **دیسکسیون اورت** = درد پاره‌شده + اختلاف فشار بازوها — **Fibrinolytic ممنوع** (مردن!).

## ⚠️ Red Flags (اقدام فوری)
1. **درد قفسه سینه + ST elevation** → STEMI — PCI / Fibrinolytic فوری.
2. **درد قفسه سینه + BP پایین + JVP بالا + رال** → RV infarction — Nitroglycerin ممنوع + مایع وریدی.
3. **درد قفسه سینه + اختلاف فشار بازوها / پALS نامتقارن** → دیسکسیون اورت — CTA + جراحی.
4. **VF / VT** → Defibrillation فوری (CPR).
5. **سینکوپ + تاکی‌کاردی / برادی‌کاردی** → Arrhythmia — Monitor + Atropine / Pace.
6. **Rales + BP پایین** → Cardiogenic Shock — Inotrope + ICU + IABP.
7. **درد جدید + وزش نو (MR / VSD)** → Mechanical Complication — Echo + جراحی.

## 🎯  قدم کوچک کنار بستر
1. **ECG 12 لید** یک مریض درد سینه را در ۱۰ دقیقه اول بگیر و بخوان.
2. **ST elevation** را در ۲ لید مجاور بشناس (V2-V3 / I-aVL / V1-V6).
3. **Troponin** یک مریض NSTEMI را بخوان (99th percentile).
4. **JVP + Rales + BP** را در یک مریض MI معاینه کن (Killip class).
5. **Aspirin ۳۰۰ mg** را به یک مریض ACS بده و زمان‌بندی را یادداشت کن.

## 🔗 اتصال به فصل‌های پیشین
- **فصل ۱ (رهیافت به مریض و علایم حیاتی):** علایم حیاتی + SpO2 — پایهٔ مدیریت ACS.
- **فصل ۵ (رهیافت و معاینهٔ قلب):** S3 + وزش MR — اختلاط MI.

## 🔁 مرور ۶۰ ثانیه‌ای (5 Questions)
1. STEMI = Reperfusion در چند دقیقه؟ **PCI ۹۰ / Fibrinolytic ۳۰ دقیقه.**
2. اولین دوا ACS؟ **Aspirin ۳۰۰ mg chewed.**
3. Ticagrelor دوز شروع + ادامه؟ **۱۸۰ mg → ۹۰ mg BID، ۱۲ ماه.**
4. Nitroglycerin را در چه MI ندهی؟ **RV infarction (inferior + JVP بالا).**
5. کنترااندیکاسیون مطلق Fibrinolytic؟ **خونریزی مغزی سابق / سکته مغزی ۳ ماه اخیر / دیسکسیون.**
