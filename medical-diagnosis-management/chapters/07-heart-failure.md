# فصل ۷ — عدم کفایه قلب (Heart Failure)

> **بخش دوم — سیستم قلب و عروق**

## 🩺 مریض این فصل

بی‌بی حوا، ۶۷ ساله، از دو هفته هنگام راه رفتن نفسش تنگ می‌شود. سه شب است که باید با دو بالشت بخوابد و نیم‌شب با تنگی نفس بیدار می‌شود. پاهایش پندیده‌اند. پنج سال پیش «حملهٔ قلبی» داشته است. در معاینه: JVP بلند، Crackles در قاعدهٔ هر دو ریه، و S3.

داکتر جوان می‌پرسد: «این پنومونی است یا قلب؟» و بعد: «اگر قلب است، کدام نوع؟ و کدام دواها عمر او را دراز می‌کنند؟»

---

🖼 **تمثیل ذهنی:** قلب یک پمپ دو اتاقه است که باید خون را در دو مدار (ریوی و بدن) بچرخاند. «عدم کفایه قلب» یعنی این پمپ یا **ضعیف شده** (نمی‌تواند خوب بپمپد — مثل پمپ خراب) یا **سفت شده** (خون را خوب پر نمی‌کند — مثل یک کیسه لاستیک پیر و سفت). نتیجه هر دو یکی است: خون برمی‌گردد و در ریه (تنگی نفس) و بدن (ادیما پا) جمع می‌شود.

## 🔹 ۱. Core Concept (مفهوم بنیادی)

عدم کفایه قلب (Heart Failure) یک **سندروم بالینی** است — نه یک مرض خاص — که در آن قلب نمی‌تواند خون کافی برای نیاز بافت‌ها با فشار مناسب پمپ کند، و یا برای پرشدن به فشار بالا نیاز دارد. دو مبنای فزیولوژیک:

- **HF با Ejection fraction کم (HFrEF):** LVEF ≤ ۴۰ فیصد — مشکل پمپاژ (سیستولیک)
- **HF با Ejection fraction محفوظ (HFpEF):** LVEF ≥ ۵۰ فیصد — مشکل پرشدن (دیاستولیک)

## 🔹 ۲. Definition & Classification (تعریف و تصنیف)

**تعریف ESC 2021:** عدم کفایه قلب یک سندروم با اعراض و علایم مشخصه است که بر اثر ناهنجاری ساختاری و یا وظیفوی قلب ایجاد می‌شود.

### تصنیف بر اساس LVEF (ESC 2021):
| نوع | LVEF | ویژگی |
|---|---|---|
| **HFrEF** (Reduced) | ≤ ۴۰٪ | مشکل انقباضی — پاسخ به «چهار ستون» تداوی |
| **HFmrEF** (Mildly Reduced) | ۴۱–۴۹٪ | میانه — مدیریت شبیه HFrEF |
| **HFpEF** (Preserved) | ≥ ۵۰٪ | مشکل انعطاف/پرشدن — چاقی، فشار خون، دیابت |

### تصنیف NYHA (کلاس عملکردی):
| کلاس | شرح |
|---|---|
| **I** | محدودیت فعالیت جسمی ندارد — فعالیت عادی بدون اعراض |
| **II** | محدودیت خفیف — فعالیت عادی اعراض می‌سازد (تنگی نفس با راه‌رفت سریع) |
| **III** | محدودیت متوسط — فعالیت کمتر از عادی هم اعراض می‌سازد |
| **IV** | اعراض در استراحت هم — هر فعالیت اضافی بدتر می‌کند |

### تصنیف Killip (در HF حاد با MI):
- کلاس ۱: بدون رال ریوی
- کلاس ۲: رال قاعده‌ای / S3
- کلاس ۳: ادیما ریوی کامل
- کلاس ۴: شوک

## 🔹 ۳. Pathophysiology — Step-by-step (میکانیزم زنجیره‌ای)

⚗️ **فرمول:** `HF = ضعف/سفتی پمپ ←↑ پیش‌بار (Preload) و پس‌بار (Afterload) ←↑ Renin–Angiotensin–Aldosterone (RAAS) و سیمپاتیک ← بازجذب آب/نمک ← احتباس مایعات ← تنگی نفس و ادیما ← HF بدتر ← حلقهٔ معیوب (Vicious cycle)`

1. **قدم ۱ — ضربه اولیه:** MI، فشار بلند خون مزمن، دریچه‌ای (Valvular)، کاردیومیوپاتی (الکهولی، ویروسی، کیموتراپی) → کاهش Contractility یا افزایش سفتی.
2. **قدم ۲ — کاهش Cardiac Output:** مغز و گرده خون‌رسانی کم می‌گیرند → **فعال‌شدن RAAS + سیستم سیمپاتیک** (پاسخ جبران‌دهنده).
3. **قدم ۳ — بازجذب سودیم و آب:** آلدوسترون و ADH → گرده نمک و آب نگه می‌دارد → **حجم خون بالا می‌رود** → پیش‌بار بالا.
4. **قدم ۴ — بازسازی بطین (Remodeling):** قلب بزرگ و بیضی می‌شود، عضله با فیبروز جایگزین می‌شود → HF بدتر.
5. **قدم ۵ — احتقان وریدی (Venous Congestion):** فشار رگ‌ها بالا → رال ریوی (چپ) + ادیما پا (راست).
6. **قدم ۶ — عدم کفایه ارگان‌های دور:** «سندروم کاردیورنل (Cardiorenal syndrome)» — گرده و کبد کم خون‌رسانی می‌شوند.

🖼 **تصویر:** «پمپ ضعیف → بدن فکر می‌کند آب کم است → آب جمع می‌کند → ریه خیس می‌شود → پمپ بیشتر خسته می‌شود» — این **حلقهٔ معیوب (Vicious cycle)** است که تداوی را می‌شکند.

## 🔹 ۴. Etiology & Risk Factors (اسباب)

| دسته | امراض |
|---|---|
| **عروقی** | فشار بلند خون (شایع‌ترین)، CAD / سکته قلبی (شایع‌ترین سبب HFrEF) |
| **دریچه‌ای** | تنگی و عدم کفایهٔ دریچهٔ اورت، عدم کفایه و تنگی دریچهٔ میترال (در افغانستان اکثراً روماتیزمی — فصل ۹) |
| **کاردیومیوپاتی** | Dilated (الکهولی، ویروسی، کیموتراپی، ارثی، Peripartum)، Hypertrophic (HCM) |
| **ریوی** | COPD، امبولی ریوی مزمن (HF راست) |
| **ریتمی** | تاکیکاردی مزمن (Tachycardia-induced)، فیبریلیشن دهلیزی |
| **متابولیک/اندوکراین** | دیابت، هایپرتایروئیدی یا هایپوتایروئیدی |
| **High-output** | انمی شدید، تایروتوکسیکوز، فیستول شریانی–وریدی، کمبود Thiamine (Beriberi)، Paget |
| **عوامل تشدید** (HF موجود را بدتر می‌کنند) | انتان، AF و تاکی‌اریتمی، ایسکیمی، فشار بلند کنترول‌نشده، قطع دوا، نمک یا مایع زیاد، NSAIDs، Steroid، Verapamil/Diltiazem در HFrEF، انمی، AKI |

## 🔹 ۵. Symptoms & Signs (اعراض و علایم)

**اعراض:**
- **تنگی نفس (Dyspnea):** با فعالیت → در استراحت (Progressive)
- **Orthopnea:** تنگی نفس در خوابیدن مسطح — با بالشت بالا بهتر
- **PND (Paroxysmal Nocturnal Dyspnea):** بیدار شدن در شب با تنگی نفس شدید
- خستگی و ضعف، کم‌اشتهایی؛ سرفهٔ شبانه
- بلند رفتن سریع وزن (احتباس مایع) — مریض را بیاموز که بیش از ۲ کیلوگرام در ۳ روز را خبر دهد

**علایم (چپ + راست):**
| علامت | سیستم |
|---|---|
| Rales / Crackles قاعده‌ای، ویز (Wheeze) | چپ (ریه) |
| **S3 Gallop** | چپ |
| JVP بلند، Hepatojugular reflux | راست |
| ادیما پا (Pitting)، کبد بزرگ (Hepatomegaly) | راست |
| مرمر عدم کفایهٔ میترال (چپ) یا ترایکسپید (راست) | هر دو |
| ضربان تیز، نبض ضعیف، هایپوتنشن و اطراف سرد (مرحلهٔ پیشرفته) | هر دو |

## 🔹 ۶. Clinical Examination (معاینه)

📋 **چک‌لیست معاینه HF:**
- ☐ علایم حیاتی: تاکیکاردی، تاکی‌پنه، SpO2
- ☐ **JVP:** ارتفاع (بیش از ۴ cm بالای زاویهٔ Louis = بلند)؛ Hepatojugular reflux
- ☐ **ریه:** Crackles قاعده‌ای، افیوژن پلورا
- ☐ **قلب:** ریتم (فیبریلیشن؟)، S3 / S4، مرمر دریچه‌ای
- ☐ **بطن:** کبد بزرگ و دردناک، Ascites
- ☐ **پاها:** ادیما Pitting (درجه ۱–۴)
- ☐ **وزن:** مقایسه با وزن قبل (احتباس)
- ☐ **SpO₂:** کمتر از ۹۰ فیصد = اکسیجن (ESC)

## 🔹 ۷. Quick Differential Diagnosis (تشخیص تفریقی)

| تشخیص | نکتهٔ تمایز |
|---|---|
| COPD / آسما | سابقهٔ سگرت، زفیر طولانی، Wheeze؛ اسپیرومتری؛ NT-proBNP نورمال |
| آمبولی ریوی | تنگی نفس ناگهانی، درد پلورایی، ریهٔ پاک؛ D-dimer، CTPA (فصل ۱۴) |
| پنومونی | تب، بلغم، Crackles یک‌طرفه، CRP؛ اما پنومونی HF را هم تشدید می‌کند |
| تامپوناد یا پریکاردیت انقباضی | JVP بسیار بلند با ریهٔ پاک، Pulsus paradoxus یا Kussmaul؛ Echo (فصل ۱۱) |
| انمی شدید | تنگی نفس + رنگ‌پریدگی + CBC |
| تایروتوکسیکوز | ضربان تیز، لرزه، گواتر؛ TSH (فصل ۴۸) |
| Peripartum cardiomyopathy | HF در ماه آخر حاملگی تا ۵ ماه پس از ولادت (فصل ۸۳) |
| سندروم نفروتیک / سیروز | ادیما با JVP نورمال؛ پروتین زیاد در ادرار یا آثار مرض کبد (فصل ۳۷، ۳۲) |

## 🔹 ۸. Investigations — Basic → Advanced

**بنیادی (هر مریض HF جدید):**
- **BNP / NT-proBNP (ESC 2021):** در شروع تدریجی (مزمن) BNP ۳۵ pg/mL یا بیشتر، یا NT-proBNP ۱۲۵ pg/mL یا بیشتر → Echo لازم است؛ در HF حاد BNP ۱۰۰ یا بیشتر، یا NT-proBNP ۳۰۰ یا بیشتر. رقم پایین‌تر HF را تقریباً رد می‌کند. چاقی رقم را پایین و AF، سن و CKD رقم را بلند می‌برند.
- **ECG ۱۲ لید:** ریتم (فیبریلیشن؟)، LVH، Q waves (MI سابق)
- **CBC:** انمی (سبب HF)
- **RFT + الکترولیت‌ها:** کراتینین، K⁺ (قبل از ACEI/MRA)
- **LFT:** احتقان کبد (Congestive hepatopathy)
- **TSH:** امراض تایروئید
- **قند خون / HbA1c:** دیابت
- **رادیوگرافی قفسه سینه (CXR):** Cardiomegaly (CTR > ۰.۵)، Pulmonary Edema، Kerley B lines
- **Echo (TTE):** **LVEF** (معیار اصلی)، پرشدن (Diastolic)، دریچه‌ها، فشار شریان ریوی

**پیشرفته / خاص:**
- **Cardiac MRI:** نوع کاردیومیوپاتی، Myocarditis، Amyloidosis
- **Angiography کرونری یا تست غیرتهاجمی:** جستجوی CAD در HFrEF
- **SpO2 / ABG:** در HF حاد
- **Echo تکرار:** بعد از ۳–۶ ماه (تغییر LVEF)

## 🔹 ۹. Diagnosis & Diagnostic Criteria

**تشخیص HF (ESC 2021) — هر دو:**
1. **اعراض و/یا علایم** عدم کفایه قلب (تنگی نفس، خستگی، ادیما)
2. **شواهد عینی** ناهنجاری قلبی (Echo: LVEF کم و/یا پر شدن مختل + BNP/NT-proBNP بالا + CXR)

**تشخیص HFrEF:** LVEF ≤ ۴۰٪ + اعراض/علایم HF
**تشخیص HFpEF:** LVEF ≥ ۵۰٪ + اعراض/علایم HF + **شواهد پر شدن مختل** (Echo diastolic / BNP بالا / همزمانی: چاقی، فشار خون، دیابت، سن بالا)

## 🔹 ۱۰. Management (تداوی)

### الف) Emergency & General Care (HF حاد / Decompensated)

📋 **الگوریتم HF حاد:**
1. **قدم ۱ — ABC + وضعیت نشسته** (بالشت ۳۰–۴۵ درجه) + اکسیجن اگر SpO₂ کمتر از ۹۰٪ (ESC 2021)
2. **قدم ۲ — تشخیص:** ECG (ریتم/MI)، BNP، CXR، RFT، K⁺
3. **قدم ۳ — دیورتیک وریدی (Furosemide):**
   - اگر **قبلاً Diuretic نمی‌گرفت:** Furosemide **۲۰–۴۰ mg IV**
   - اگر **قبلاً Diuretic فمی می‌گرفت:** ۱ تا ۲ برابر دوز روزانهٔ فمی، به شکل IV
   - پاسخ را ببین: Sodium ادرار پس از ۲ ساعت یا حجم ادرار در ۶ ساعت اول (ESC 2021). اگر پاسخ کم بود، دوز Loop را دو برابر کن؛ اگر باز هم کم بود، یک Thiazide یا Acetazolamide اضافه کن (نه دو Loop diuretic با هم).
4. **قدم ۴ — Vasodilator** (اگر BP سیستولیک > ۱۰۰): **Nitroglycerin** IV ۱۰–۲۰ mcg/min شروع، افزایش هر ۵ دقیقه تا ۲۰۰ mcg/min — یا **Nitroprusside** ۰.۳ mcg/kg/min (تا ۵ mcg/kg/min)
5. **قدم ۵ — درد صدر یا MI:** تداوی ACS (فصل ۸)
6. **قدم ۶ — AF با ضربان تیز:** کنترول ضربان با Digoxin IV یا Amiodarone IV؛ اگر ناپایدار → Cardioversion (فصل ۱۰)
7. **قدم ۷ — شوک کاردیوجنیک:** Inotrope (Dobutamine)، Vasopressor (Noradrenaline)، و در مراکز مجهز حمایت میخانیکی دوران (فصل ۷۷)
8. **قدم ۸ — تنفس:** NIV (CPAP/BiPAP) اگر تاکی‌پنه / ادیما ریوی — اگر ناکافی → Intubation
9. **قدم ۹ — پایش:** ادرار ساعتی، K⁺، Cr، وزن روزانه

### ب) Pharmacotherapy — چهار ستون HFrEF (ESC 2021 / AHA 2022)

⚗️ **فرمول ۴ ستون:**
`HFrEF = (ARNI/ACEI/ARB) + (Beta-blocker) + (MRA) + (SGLT2i) — هم‌زمان، دوز کم شروع، تدریجی افزایش`

**ستون ۱ — RAAS Blocker (ARNI > ACEI/ARB):**
| دوا | دوز شروع | افزایش | دوز حداکثر | راه/تکرار | یادداشت |
|---|---|---|---|---|---|
| **Sacubitril/Valsartan (ARNI)** | ۲۴/۲۶ mg یا ۴۹/۵۱ mg | ۲–۴ هفته | ۹۷/۱۰۳ mg | PO / BID | حد اقل ۳۶ ساعت پس از آخرین دوز ACEI (خطر Angioedema) |
| **Enalapril** (بدیل) | ۲.۵ mg دو بار | ۲ هفته | ۱۰–۲۰ mg BID | PO / BID | سرفهٔ خشک |
| **Ramipril** | ۲.۵ mg | ۲ هفته | ۱۰ mg OD | PO / OD | |
| **Lisinopril** | ۵ mg | ۲ هفته | ۴۰ mg OD | PO / OD | |
| **Losartan** (ARB) | ۲۵–۵۰ mg | ۲ هفته | ۱۵۰ mg OD | PO / OD | اگر ACEI سرفه ساخت |

**ستون ۲ — Beta-blocker (سه دوا اثبات‌شده):**
| دوا | دوز شروع | دوز حداکثر | راه/تکرار |
|---|---|---|---|
| **Carvedilol** | ۳.۱۲۵ mg | ۲۵ mg BID (وزن <۸۵ kg) / ۵۰ mg BID (وزن >۸۵ kg) | PO / BID |
| **Bisoprolol** | ۱.۲۵ mg | ۱۰ mg | PO / OD |
| **Metoprolol Succinate** | ۱۲.۵ mg | ۲۰۰ mg | PO / OD |

> ⚠️ **Beta-blocker را فقط در HF پایدار (بدون احتباس حاد) شروع کن** — دوز کم، هر ۲ هفته دو برابر کن، تا دوز هدف یا حداکثر تحمل.

**ستون ۳ — MRA (Mineralocorticoid Receptor Antagonist):**
| دوا | دوز | راه/تکرار | کنترااندیکاسیون |
|---|---|---|---|
| **Spironolactone** | ۲۵–۵۰ mg | PO / OD | K⁺ > ۵.۵، eGFR < ۳۰ |
| **Eplerenone** (بعد از MI) | ۲۵–۵۰ mg | PO / OD | K⁺ > ۵.۵، eGFR < ۳۰ |

**ستون ۴ — SGLT2 Inhibitor (تمام HFrEF، با یا بدون دیابت):**
| دوا | دوز | راه/تکرار | یادداشت |
|---|---|---|---|
| **Dapagliflozin** | ۱۰ mg | PO / OD | eGFR > ۲۵ |
| **Empagliflozin** | ۱۰ mg | PO / OD | eGFR > ۲۰ |

**HFmrEF و HFpEF — تازه‌سازی ESC 2023:**
- **SGLT2 Inhibitor** (Dapagliflozin یا Empagliflozin، همان دوز بالا) برای **HFmrEF** و **HFpEF** توصیه می‌شود تا بستری شدن به علت HF یا مرگ قلبی کم شود (Class I، سطح A؛ کارآزمایی‌های EMPEROR-Preserved و DELIVER).
- در HFpEF باقی تداوی: Diuretic برای احتقان و تداوی جدی امراض همراه (فشار خون، AF، چاقی، دیابت).
- **آهن وریدی (IV iron):** در HFrEF یا HFmrEF باعلامت همراه کمبود آهن، برای بهتر شدن علایم و کیفیت زندگی (Class I).
- **دیابت نوع ۲ + CKD:** SGLT2 Inhibitor و **Finerenone** برای کاهش بستری شدن به علت HF (Class I). دوز Finerenone تخصصی است و این‌جا نوشته نمی‌شود (→ فصل ۳۹).

**دواهای کمکی (Adjunctive):**
| دوا | دوز | اندیکاسیون |
|---|---|---|
| **Digoxin** | ۰.۰۶۲۵–۰.۲۵ mg روزانه | PO — AF با HF، یا علایم باقی با وجود تداوی؛ در سالخورده و CKD دوز کم |
| **Hydralazine + ISDN** | ۳۷.۵ mg + ۲۰ mg سه بار در روز، تا ۷۵ mg + ۴۰ mg سه بار | PO — اگر ACEI، ARB و ARNI هیچ‌کدام ممکن نیست (یا در مریضان سیاه‌پوست همراه تداوی کامل) |
| **Ivabradine** | ۵ mg دو بار → ۷.۵ mg دو بار | PO — HFrEF با ریتم سینوسی و ضربان ۷۰ یا بیشتر، با وجود Beta-blocker |
| **Vericiguat** | ۲.۵ → ۱۰ mg | PO / OD — بعد از Decompensation |

**Dosing در عدم کفایه گرده:**
- ACEI/ARB: eGFR < ۳۰ — احتیاط + پایش K⁺/Cr
- Spironolactone: eGFR < ۳۰ — ممنوع
- Furosemide: eGFR < ۳۰ — دوز بالاتر (۸۰–۱۶۰ mg)
- SGLT2i: eGFR < ۲۰–۲۵ — شروع نکن

### ج) Non-pharmacological Management
- **محدودیت نمک:** کمتر از ۵–۶ گرم/روز
- **محدودیت مایعات:** ۱.۵–۲ لیتر/روز (در احتباس مقاوم)
- **وزن روزانه:** افزایش ۲ کیلو در ۳ روز → تماس با داکتر
- **فعالیت:** ورزش منظم و تدریجی در مریض پایدار (Cardiac rehabilitation)
- **ترک سگرت و الکهول:** ضروری
- **واکسین:** انفلونزا (هر سال) و Pneumococcal
- **چربی/قند/دیابت:** کنترول
- **دواهای خطرناک را قطع کن:** NSAID، کورتیکوستیروئید، Verapamil/Diltiazem (در HFrEF)

### د) Surgical / Procedural Management
- **CABG / PCI:** در CAD (HFrEF + ایسکیمی)
- **ترمیم دریچه / تعویض (TAVI/SAVR):** دریچه‌ای (استنوز/ناکافی)
- **CRT (Cardiac Resynchronization Therapy):** LVEF ۳۵٪ یا کمتر با وجود تداوی بهینه + ریتم سینوسی + LBBB با QRS ۱۵۰ ms یا بیشتر (Class I؛ ۱۳۰–۱۴۹ ms: IIa)
- **ICD (Implantable Cardioverter-Defibrillator):** LVEF ۳۵٪ یا کمتر + NYHA II–III پس از حد اقل ۳ ماه تداوی بهینه (در ایسکیمیک قوی‌تر از غیرایسکیمیک)
- **پیوند قلب (Transplant):** NYHA IV مقاوم — معیارهای خاص

## 🔹 ۱۱. Complications (اختلاطات)
- **ریوی:** ادیما ریوی، پنومونی، آمبولی ریوی (DVT)
- **عروقی:** سکته قلبی، سکته مغزی (فیبریلیشن)
- **گرده:** سندروم کاردیورنل (Cardiorenal syndrome)، AKI
- **کبد:** احتقان کبد (Congestive hepatopathy)، Ascites
- **ریتمی:** فیبریلیشن، تاکیکاردی، VF
- **عصبی:** Delirium؛ سکتهٔ مغزی آمبولیک در AF
- **ترومبوتیک:** DVT / PE (بسیار شایع در HF)
- **پیشرفته:** شوک کاردیوجنیک، مرگ ناگهانی (Sudden Cardiac Death)

## 🔹 ۱۲. Prognosis & Follow-up
- **پروگنوز:** بدون تداوی بهینه حدود نیم مریضان در ۵ سال فوت می‌کنند؛ چهار ستون تداوی و CRT/ICD در مریضان مناسب این رقم را به طور واضح کم کرده‌اند.
- **پیگیری:**
  - هر ۲–۴ هفته تا پایدار
  - K⁺ + Cr: ۱–۲ هفته بعد از هر تغییر دوز (ACEI/MRA/SGLT2i)
  - Echo: ۳–۶ ماه اول، سپس سالانه
  - BNP/NT-proBNP: پیگیری روند
  - آموزش: وزن روزانه، محدودیت مایعات/نمک، علامات هشدار

## ↩️ برگشت به مریض

- **قلب یا ریه؟** Orthopnoea، PND، JVP بلند، S3 و پندیدگی پاها با سابقهٔ MI، همه به **عدم کفایهٔ قلب با احتقان** اشاره دارند. تب و بلغم چرکی نداشت.
- **تأیید:** NT-proBNP بلند و Echocardiography: **EF کاهش‌یافته (HFrEF)** با حرکت‌نکردن دیوار قدامی (اثر MI قدیمی).
- **امروز:** Loop diuretic وریدی برای رفع احتقان، با نظارت وزن، ادرار، کریاتینین و پوتاشیم (بخش ۱۰).
- **برای عمر دراز:** پس از پایدار شدن، **چهار ستون تداوی HFrEF** یکی‌یکی شروع و تا دوز قابل تحمل بلند شد (بخش ۱۰). Diuretic علایم را بهتر می‌کند، اما مرگ را کم نمی‌کند؛ این چهار ستون می‌کنند.
- **رخصت:** وزن روزانه، محدودیت نمک، و علایمی که باید فوراً برگردد.

## 💡 Memory Joggers (نکات طلایی)
1. **HF = سندروم، نه یک مرض.** LVEF را بدان: ≤ ۴۰ = HFrEF، ≥ ۵۰ = HFpEF.
2. **S3 در کاهل بالای ۴۰ سال** به نفع عدم کفایهٔ قلب است؛ جدی بگیر.
3. **PND (بیدار شدن شبانه با تنگی نفس) = نشانهٔ کلاسیک HF چپ.**
4. **۴ ستون HFrEF:** ARNI/ACEI + Beta-blocker + MRA + SGLT2i — همه ۴ تا، دوز کم شروع.
5. **Beta-blocker را در احتباس حاد شروع نکن** — اول احتباس را بشکن، بعد Beta-blocker.
6. **Furosemide IV = ۱ تا ۲ برابر دوز فمی روزانه** (اگر قبلاً فمی می‌گرفت).
7. **K⁺ + Cr را ۱–۲ هفته بعد از هر تغییر ACEI/MRA چک کن.**
8. **LVEF ≤ ۳۵٪ + LBBB + QRS ≥ ۱۵۰ → CRT.** **LVEF ≤ ۳۵٪ پس از ۳ ماه تداوی بهینه → ICD.**

## ⚠️ Red Flags (اقدام فوری)
1. **تنگی نفس حاد + Orthopnea + Rales** → HF حاد / ادیما ریوی — اکسیجن + Furosemide IV.
2. **SpO2 < ۹۰٪ + تاکی‌پنه** → NIV (CPAP/BiPAP) → اگر ناکافی Intubation.
3. **BP سیستولیک < ۹۰ + سردی/تعریق + کاهش ادرار** → شوک کاردیوجنیک — Inotrope + ICU.
4. **درد سینه + ECG جدید (ST elevation)** → ACS هم‌زمان — مدیریت MI.
5. **AF با ضربان تیز و مریض ناپایدار** → Cardioversion فوری (فصل ۱۰).
6. **بلند رفتن وزن بیش از ۲ کیلوگرام در ۳ روز** → احتباس مایع — با داکتر تماس بگیرد تا دوز Diuretic تنظیم شود.
7. **K⁺ بیشتر از ۵.۵ پس از ACEI/MRA** → دوز را کم یا قطع کن، ECG بگیر (T بلند و نوک‌تیز).

## 🎯 ۵ قدم کوچک کنار بستر
1. **S3** را در یک مریض HF بشنو (کمی پس از S2، آواز بم؛ با Bell در رأس قلب).
2. **JVP** یک مریض HF را اندازه بگیر (بیش از ۴ cm بالای زاویهٔ Louis = بلند).
3. **BNP/NT-proBNP** یک مریض تنگی نفس را چک کن و تفسیر کن.
4. **Echo** یک مریض HFrEF را ببین (LVEF + پرشدن + دریچه‌ها).
5. **CXR** یک مریض HF را بخوان (CTR، توزیع مجدد عروق، Kerley B، افیوژن).

## 🔗 اتصال به فصل‌های پیشین
- **فصل ۱ (رهیافت به مریض و علایم حیاتی):** JVP + ادیما + علایم حیاتی — پایهٔ معاینه HF.
- **فصل ۵ (رهیافت و معاینهٔ قلب):** S3/S4 + مرمر دریچه‌ای — تشخیص HF.
- **فصل ۲ (ECG):** فیبریلیشن + LVH + Q waves — سبب و پیگیری.
- **فصل ۶ (فشار خون):** فشار بلند خون = شایع‌ترین سبب HF.
- **فصل ۸ (ACS):** MI = شایع‌ترین سبب HFrEF + ACS هم‌زمان.
- **فصل ۹ (دریچه‌ها):** دریچه‌ای = سبب HF — Echo.
- **فصل ۱۰ (فیبریلیشن):** فیبریلیشن + HF — Rate control + آنتی‌کواگولاسیون.
- **فصل ۱۴ (DVT/PE):** DVT/PE = اختلاط شایع HF.

## 🔁 مرور ۶۰ ثانیه‌ای (5 Questions)
1. HFrEF = LVEF چند؟ **≤ ۴۰٪.**
2. چهار ستون HFrEF؟ **ARNI/ACEI + Beta-blocker + MRA + SGLT2i.**
3. Beta-blocker را در احتباس حاد شروع می‌کنی؟ **نه** — اول احتباس.
4. Furosemide IV در مریض با Furosemide فمی قبلی؟ **دو برابر دوز روزانهٔ فمی.**
5. LVEF ≤ ۳۵٪ + LBBB + QRS > ۱۳۰ → چه دسایسی؟ **CRT.**
