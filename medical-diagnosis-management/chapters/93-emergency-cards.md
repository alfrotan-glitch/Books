# ضمیمهٔ ۹۳ — کارت‌های عاجل: دقیقه‌های اول

> **این ضمیمه چیز تازه نمی‌گوید.** هر عدد این‌جا از یک فصل کتاب گرفته شده که منبع آن در همان فصل آمده و در `release/dose-verification-log.md` ثبت شده است. هدف: وقتی مریض پیش رویت است و وقت خواندن فصل نیست. **پیش از استعمال، فصل مربوطه را حداقل یک بار خوانده باش** — کارت جای فهم را نمی‌گیرد. دوزها برای **کاهلان** است مگر خلاف آن نوشته شده باشد.

## ۱. ایست قلبی (فصل ۷۸ — AHA 2025)
| | |
|---|---|
| تشخیص | جواب نمی‌دهد + تنفس عادی ندارد (Gasping هم) → **فشار صدر** |
| فشار صدر | عمق **۵–۶ cm**، **۱۰۰–۱۲۰/دقیقه**، برگشت کامل؛ **۳۰:۲**؛ با راه هوایی پیشرفته **۱ تنفس هر ۶ ثانیه** |
| VF / VT بی‌نبض | **شاک** (Monophasic ۳۶۰ J) → ۲ دقیقه CPR |
| Epinephrine | **۱ mg وریدی/IO هر ۳–۵ دقیقه**؛ Asystole/PEA: زود؛ VF: پس از ناکامی شاک‌های اول |
| VF مقاوم | **Amiodarone ۳۰۰ mg**، سپس **۱۵۰ mg**؛ یا **Lidocaine ۱–۱.۵ mg/kg** |
| همیشه | **H و T** را بجوی |

## ۲. Anaphylaxis (فصل ۸۲ — RCUK 2021)
| | |
|---|---|
| **Adrenaline عضلی (ران)** | **بالای ۱۲ سال: ۵۰۰ microgram** · ۶–۱۲: ۳۰۰ · کمتر از ۶: ۱۵۰ |
| تکرار | **پس از ۵ دقیقه** اگر مشکل A/B/C باقی است |
| مایع | کاهل **۵۰۰–۱۰۰۰ ml**؛ طفل **۲۰ ml/kg** |
| مقاوم (پس از دو دوز IM) | انفیوژن Adrenaline توسط شخص مجرب |
| **نه اول** | Antihistamine (خط سوم)؛ Steroid روتین نه |

## ۳. Status epilepticus (فصل ۷۳ — ENLS 5.0، AES 2016)
| دقیقه | کار |
|---|---|
| ۰–۵ | ABC، **قند**، (Thiamine در الکهول/سوء تغذیه) |
| ۵–۲۰ | **Lorazepam ۰.۱ mg/kg وریدی (اعظمی ۴ mg)**، یک بار تکرار · یا **Midazolam ۱۰ mg عضلی** · یا Diazepam ۰.۱۵ mg/kg وریدی (اعظمی ۱۰ mg) |
| ۲۰–۴۰ | یکی: **Levetiracetam ۶۰ mg/kg (اعظمی ۴.۵ g)** · **Valproate ۴۰ mg/kg** در ۱۰ دقیقه · **Fosphenytoin ۲۰ mg PE/kg** |
| بیشتر از ۴۰ | ICU؛ انفیوژن Midazolam |
| حامله | **Eclampsia → Magnesium** (کارت ۷) |

## ۴. مننژیت باکتریایی مشکوک (فصل ۷۵ — ESCMID 2016، NHS Highland)
| | |
|---|---|
| ترتیب | کلچر خون → **Dexamethasone + Antibiotic** → (CT در صورت ضرورت) → LP. **Antibiotic را به خاطر LP یا CT به تأخیر نینداز** |
| Dexamethasone | **۱۰ mg وریدی هر ۶ ساعت، ۴ روز** (طفل ۰.۱۵ mg/kg، اعظمی ۱۰) |
| کمتر از ۶۰ سال | **Ceftriaxone ۲ g هر ۱۲ ساعت** |
| ۶۰+ یا ضعف معافیت | + **Amoxicillin ۲ g هر ۴ ساعت** |
| شک به HSV | + **Aciclovir ۱۰ mg/kg هر ۸ ساعت** |
| تماس Meningococcus | **Ciprofloxacin ۵۰۰ mg** یک دوز (حامله: **Ceftriaxone ۲۵۰ mg IM**) |

## ۵. سکتهٔ مغزی حاد (فصل ۷۲ — AHA/ASA 2026)
| | |
|---|---|
| اول | **قند**؛ CT/CTA بدون تأخیر |
| Thrombolysis (تا ۴.۵ ساعت) | **Tenecteplase ۰.۲۵ mg/kg (اعظمی ۲۵ mg)** یک Bolus · یا **Alteplase ۰.۹ mg/kg (اعظمی ۹۰ mg)** |
| فشار | پیش از IVT **کمتر از ۱۸۵/۱۱۰**؛ ۲۴ ساعت پس از آن **کمتر از ۱۸۰/۱۰۵**؛ بدون Reperfusion تا **۲۲۰/۱۲۰** قابل قبول |
| Thrombectomy | انسداد رگ بزرگ تا **۲۴ ساعت** |

## ۶. Sepsis و شوک سپتیک (فصل ۶۰ — SSC 2021/2026)
| | |
|---|---|
| ساعت اول | کلچر، **Antibiotic**، Lactate |
| مایع | **حداقل ۳۰ mL/kg کریستالوئید در ۳ ساعت اول** برای Hypoperfusion — ارزیابی پس از هر Bolus |
| هدف | **MAP ۶۵ mmHg** (۶۵ سال یا بیشتر: **۶۰–۶۵**) |
| Vasopressor | Norepinephrine؛ از ورید محیطی شروع کن |

## ۸. Hyperkalaemia شدید (فصل ۴۲ — UKKA)
