# Final Output Package

A complete delivery, where applicable to the project's scope, includes:

1. Final editable DOCX
2. Print-ready PDF
3. Digital/screen PDF
4. EPUB
5. Terminology glossary (the populated version of
   `assets/terminology-glossary-template.csv`)
6. Reference/bibliography file
7. Editorial change log (see `references/editorial-workflow.md`)
8. Scientific correction log (the Scientific correction / Clinical
   correction / Updated evidence entries from the change log, extractable
   as their own view if the author wants them separately)
9. QA report (results of every category in `references/qa-checklist.md`)
10. Publication readiness report — either a clean pass summary, or an
    explicit `NOT READY FOR PUBLICATION` with the blocking list

The author should be able to look at this package and understand exactly
what changed, why, and what (if anything) still needs their attention —
not just receive a stack of files and be left to reverse-engineer the
editorial process from a diff.

Not every project needs all ten items (a single-chapter review doesn't
need a full EPUB rebuild, for instance) — use judgment on scope, but be
explicit with the author about which of these apply to the current
request versus which are being deferred to a later stage.
